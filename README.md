# The Fitness Hub

A static fitness web app that helps users build personalised workout plans — no sign-up, no data collection required.

## Features

- **Workout Generator** — pick your fitness level, session length, focus area, and available equipment; get a ready-to-use 3-day or 5-day plan instantly
- **Exercise Library** — browse exercises with form tips and prescriptions
- **Weekly Plan** — structured weekly workout schedules
- **Nutrition Guide** — practical nutrition tips
- **Articles** — fitness education and training advice
- **Glossary** — plain-English definitions of fitness terms

## Pages

| Page | Description |
|------|-------------|
| Home | Landing page with featured exercises and testimonials |
| Generator | Core tool — generates a custom workout plan |
| Exercise Library | Browse all exercises with details |
| Weekly Plan | Pre-built weekly training schedules |
| Nutrition | Nutrition guidelines |
| Articles | Fitness articles |
| Glossary | Terminology reference |
| About | About the project |

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- No frameworks, no build tools, no dependencies
